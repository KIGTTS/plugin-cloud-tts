# Source origin

This repository is an independent KIGTTS plugin. Its service shell and system TTS support are derived from the KIGTTS speech-service source at commit 36e4d8fbb1a199009c01c95ae65f4e97b1759e81; the original GPL-3.0-only notices are preserved. The cloud provider configuration, manually curated voice-pack model, provider tags and HTTPS adapter were added here. The SDK and tts-support dependencies are pinned as submodules and no credentials or user data are included.
